# LocalTools Suite Privacy Policy

Effective date: 16 August 2026

LocalTools Suite is an offline desktop file-processing application published by
Furkan Ertürk. The application does not require an account, display advertising,
use analytics, or transmit files or usage telemetry to the publisher.

## Data processed

- Files selected by the user are read locally to perform the requested operation.
- Output files are written only to a location selected by the user or to the
  application's local LocalTools output folder.
- Application preferences, favorites and—when enabled—the ten most recent file
  paths are stored locally in the current Windows user profile.
- Local diagnostic logs contain timestamps, severity, component and bounded
  technical status messages. They do not intentionally contain file paths or
  document contents. One current and one rotated log are retained locally.
- Temporary working files may be created under the Windows temporary directory.
  Automatic cleanup is enabled by default and can also be run from Settings.
- The bundled FFmpeg and FFprobe programs process selected audio/video files as
  local child processes. No media is uploaded.

## Network access

The core tools work without an internet connection. LocalTools Suite does not
contact a publisher server. If the user explicitly chooses to open a URL decoded
from a QR code, the address is handed to the system default browser; the browser
and destination site then apply their own privacy terms.

## User controls and retention

Settings can disable and clear recent-file history and clear temporary files.
Uninstalling the application removes packaged program files; Windows or Store
behavior may retain user settings. The user may remove remaining LocalTools
Suite data from the current Windows profile.

## Sharing and sale

The publisher does not receive, sell or share personal data through the
application. Files remain on the user's device unless the user independently
moves or shares them.

## Contact

Support and privacy contact details will be published in the Microsoft Store
listing before public submission. The stable HTTPS copy of this policy must be
published before the R5 release gate can close.

This policy may be updated when application behavior changes. The effective date
above identifies this version.
